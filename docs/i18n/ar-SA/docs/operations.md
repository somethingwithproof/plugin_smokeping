<a id="operating-the-smokeping-plugin"></a>
# تشغيل إضافة SmokePing

كيفية قراءة ما تعرضه الإضافة ومعنى كل حالة وأدلتها، وما يجب فحصه عند ظهور خلل، وسلوكها عند فشل المدخلات. التثبيت في [التثبيت](install.md)، والتنبيهات في [التنبيهات](alerting.md)، والنسخ في [النسخ والاستعادة](backup-restore.md).

راجع [أدوار الوصول](../README.md#access-roles) لصلاحيات View وOperator وAdmin وسلوك الفرز الشخصي.

<a id="pages"></a>
## الصفحات

| الصفحة | النطاق | ما تعرضه |
|---|---|---|
| **SmokePing** (تبويب علوي) | View | أحدث حالة لأهداف الأجهزة المسموح لك برؤيتها، صف لكل هدف وموقع |
| **SmokePing Inventory** | Admin | جميع أهداف إعداد SmokePing، مرتبطة أم لا، ومقترحات إعادة الربط المفتوحة |
| **SmokePing Health** | Admin | الفحوص أدناه وزر إعادة محاولة استيراد القوالب |
| **SmokePing Configuration** | Admin | تصدير إعداد الإضافة واستيراده ([الصيغة](configuration-format.md)) |
| **Import SmokePing Configuration** (تحت Import/Export) | Admin | استيراد إعداد SmokePing موجود إلى أجهزة ورسوم وشجرة رسوم ([الطريقة](provisioning.md#a-whole-smokeping-configuration)) |

الرسوم الدخانية والملخصة رسوم Cacti عادية، فتحكمها صلاحيات الرسوم والأجهزة في Cacti.

<a id="what-each-state-means"></a>
## معنى كل حالة

يجمع كل صف أبعادًا مستقلة. لا تُدمج أبدًا في لون واحد، لأن توقف المجمّع والفقدان الكامل للحزم يتطلبان استجابتين مختلفتين.

| البُعد | الحالات | الدليل |
|---|---|---|
| الحداثة | `current`، `delayed`، `stale`، `never` | عمر آخر تحديث RRD (بـ `rrdtool lastupdate`) مقابل `step` للهدف. Current: ضمن `step` واحد زائد سماح الحداثة (60 ثانية افتراضيًا). Delayed: أقدم وحتى ضعفي `step`، وهو نبض SmokePing. Stale: بعد النبض حين تصبح القيم مجهولة. Never: الملف مفقود أو لم يُحدّث منذ إنشائه |
| التنفيذ | `completed`، `probe_error`، `unknown` | تكتمل الجولة عندما تكتب فقدانًا رقميًا. البيانات المتقادمة أو غير المرصودة لا تخبر عن الجولة الأخيرة، فتكون `unknown`. لا تُضبط `probe_error` أبدًا: المجس الفاشل يكتب قيم هدف لا يجيب نفسها ([البحث](../../../research/probe-failures.md)) |
| الوضع | `within_policy`، `degraded`، `complete_loss`، `unknown` | من آخر جولة مكتملة. الفقدان الكامل هو تساوي `loss` و`pings` دون وسيط. أي فقدان أقل تدهور. لا يظهر المجمّع المتوقف كفقدان؛ يتقادم ويصبح الوضع `unknown` |
| الإداري | `enabled`، `disabled`، `archived` | سجل الهدف في الإضافة. لا يُقرأ الهدف المعطّل أو المؤرشف |
| الصيانة | في الصيانة أو خارجها | خطاف Maint المسمى `is_device_in_maintenance` لجهاز الهدف، في عمود Maintenance بصفحة الأهداف. دون Maint أو عند تعطيله، تظهر كل الأجهزة خارج الصيانة |
| وقت القياس | ثوانٍ منذ آخر تحديث | طابع RRD الزمني نفسه. تحديث الصفحة لا يُحتسب قياسًا |

تأتي حداثة كل موقع من ملفه (`target~slave.rrd` للتابع)، لذا يظهر التابع المتأخر متقادمًا حتى إن كان الرئيسي حديثًا.

يعرض عمود الفقدان `lost/pings` للجولة الأخيرة، والوسيط بالمللي ثانية؛ `U` تعني مجهولًا لا صفرًا.

<a id="health-checks"></a>
## فحوص الصحة

| الفحص | معنى OK | عند عدم كونه OK |
|---|---|---|
| `php_binary` | ملف PHP التنفيذي المحدد في Cacti موجود وقابل للتنفيذ | لا يبدأ القارئ: أصلح إعداد «PHP Binary Path» في Cacti |
| `reader` | انتهت الدورة الأخيرة ضمن ثلاثة فواصل مجمّع وضمن ميزانيتها الزمنية | تحذير: القارئ متأخر أو تجاوز الميزانية. مع كثرة السلاسل ارفع الميزانية أو افحص التخزين؛ راجع [الأداء](performance.md) |
| `inventory` | حلّل آخر جرد إعداد SmokePing | خطأ: رسالة محلل SmokePing مع الملف والسطر. يبقى الجرد السابق مستخدمًا |
| `mount`، `read-only`، `writable` | مسار الربط داخل RRA ويُوصل إليه دون رابط رمزي، ومربوط للقراءة فقط وغير قابل للكتابة | خطأ. راجع [دليل التثبيت](install.md#3-mount-the-data-directory-read-only-inside-cactis-rra-path) |
| `visibility` | ملفات الجرد مرئية عبر الربط | تحذير يذكر عدد المفقود |
| `templates` | قوالب SmokePing مستوردة | خطأ مع السبب؛ أصلحه واستخدم **Retry Template Import** |
| `device_pollers` | كل جهاز ذي مصادر ملخص يستطلعه مجمّع القارئ | خطأ يسمّي الأجهزة: لا بيانات لملخصاتها وتنبيهاتها حتى يستطلعها ذلك المجمّع |
| `loss_colors` | ألوان Loss Colors المختارة: ألوان إصدار SmokePing المكتشف أو المحددة. بعد تغييرها ينقل المجمّع الرئيسي الرسوم في الدورات التالية، 200 في الدورة؛ ينقلها `upgrade-graphs` فورًا. يعدّ الصف الرسوم الباقية على الألوان الأخرى ويحذر من النقل الفاشل | مجهول إذا لم يجد القارئ إصدارًا والإعداد Automatic: تستخدم الرسوم ألوان 2.8 والأحدث. تحذير إذا خالف الإعداد الإصدار المكتشف. راجع [ألوان الفقدان](provisioning.md#loss-colors) |
| `dual_alerting` | لا هدف يجمع قيمة SmokePing `alerts` وعتبة Thold مفعّلة على مصدر ملخصه | تحذير يسمّي حتى 10 أهداف: المشكلة المطابقة للشرطين تُشعر مرتين. لا يقارن الفحص الشروط؛ مثلًا قد تعمل عتبة Thold `age` دون تنبيه فقدان SmokePing. قارن قبل إزالة تنبيه SmokePing أو تعطيل العتبة. OK إذا لم يكن Thold مثبتًا |

<a id="typical-situations"></a>
## حالات شائعة

- **كل شيء `stale`.** توقف SmokePing عن الكتابة أو تقادم الربط. افحص `systemctl status smokeping` ثم قارن `rrdtool lastupdate` عبر الربط بالملف نفسه على مضيف SmokePing. قد يتأخر NFS للقراءة فقط بمدة مخبأ السمات.
- **تابع واحد `stale` والرئيسي `current`.** توقف التابع عن التسليم. يطبق الرئيسي النتائج المتأخرة عند وصولها فيملأ الرسم الماضي؛ لا يعيد Thold تقييمها ([التنبيهات](alerting.md)).
- **هدف يعرض `never`.** ملف RRD غير موجود بعد (ينشئه SmokePing في أول جولة بعد إعادة التحميل)، أو لا يظهره الربط. افحص `visibility`.
- **رسم فارغ بعد ترقية Cacti إلى 1.2.32.** يستبدل Cacti مسار مصدر خارج RRA بمساره المولّد. تحقق من موقع الربط حسب الإضافة ومن عدم وجود روابط رمزية.
- **إعادة تسمية قسم SmokePing.** يبدأ SmokePing ملفًا جديدًا للمسار الجديد. يقترح الجرد إعادة الربط ولا يغير شيئًا حتى يؤكد المسؤول ([التجهيز](provisioning.md#re-linking-a-renamed-target)).

<a id="topologies"></a>
## البنى

1. **SmokePing على مضيف مجمّع Cacti.** يقرأ مستخدم المجمّع دليل البيانات عبر الربط المحلي. هذه حالة دليل التثبيت.
2. **مشاركة دليل بيانات SmokePing مع مضيف Cacti.** اربطه للقراءة فقط عبر NFS عند مسار RRA على المضيف الذي يشغّل مجمّع SmokePing. تقارن صفحة الصحة آخر تحديث بالساعة، فيظهر الربط المتأخر `delayed` أو `stale`. تُعرض الرسوم الدخانية على خادم واجهة الويب، لذا يحتاج المشاركة أيضًا؛ إن كانت للمجمّع وحده تعمل الملخصات والتنبيهات لكن الرسوم الدخانية فارغة.
3. **SmokePing على مجمّع بيانات Cacti بعيد** مرحلة لاحقة غير مدعومة في هذا الإصدار.

المجمّع المحدد في **SmokePing Poller** وحده يقرأ بيانات SmokePing. يجب أن يستطلع أجهزة مصادر الملخص.

<a id="when-inputs-fail"></a>
## عند فشل المدخلات

هذه السلوكيات التي أُهّل الإصدار مقابلها ([تأهيل الأعطال](../../../failure-qualification.md))؛ لا يفقد أي منها بيانات.

| العطل | السلوك الموثق |
|---|---|
| إعداد SmokePing غير قابل للقراءة أو معطوب | يفشل الجرد برسالة المحلل في Health؛ يبقى السابق ولا يُحذف شيء |
| مجس لا يعمل مع استمرار SmokePing: خروج التنفيذي بخطأ، أو عنوان المصدر ليس على المضيف، أو رفض fping لمعامل، أو تعطيل IPv6 لـ FPing6 | يكتب SmokePing فقدانًا كاملًا لكل أهداف المجس، مثل أهداف لا تجيب. تظهر القياسات `complete_loss`. إذا حدث لكل أهداف مجس معًا، ابحث في سجل SmokePing عن خطئه |
| فشل مجس يكتشفه SmokePing: ملف تنفيذي مفقود أو معامل خارج النطاق أو غياب مقبس raw لـ fping | يخرج SmokePing عند البدء أو أول جولة. تصبح كل الأهداف `delayed` ثم `stale` كما عند توقفه |
| تعذر حل أسماء مضيفي الأهداف (فشل DNS) | تفشل المجسّات وتكتب فقدانًا؛ تقرأ الإضافة ما كُتب. تظهر `degraded` أو `complete_loss` لا تقادمًا. لا تجري الإضافة استعلامات أسماء |
| توقف SmokePing أو مجمّعه | الحداثة `delayed` ثم `stale`؛ تصبح `median` و`loss_pct` مجهولتين وتواصل `age` النمو. لا فقدان صفري أبدًا |
| فرق الساعة بين Cacti وSmokePing | تقارن الحداثة وقت RRD بساعة Cacti، فيزحزح الفرق كل الأعمار. المضيف المتقدم يضع أوقاتًا مستقبلية تظهر `current`، ويظل المجمّع المتوقف `current` حتى انقضاء الفرق. المتأخر يجعل كل سلسلة أقدم بالفرق و`stale` عندما يتجاوز ضعفي `step`. أبق المضيفين على NTP |
| RRD غير مقروء أو تالف | يسجل القارئ تحذيرًا للملف ويتابع البقية. السلسلة غير المقروءة قط مجهولة (`U`). المقروءة سابقًا تحتفظ بآخر مخبأ يتقادم عبر `delayed` و`stale` إلى مجهول؛ لا يصبح الملف التالف فقدانًا صفريًا |
| امتلاء تخزين Cacti | يكتب القارئ مخبأ قاعدة البيانات فقط. عند رفض الكتابة يخرج طبيعيًا وتبقى كل الصفوف كاملة كما كانت؛ تخزن الدورة التالية بعد التعافي الجولات الجديدة. تفشل RRD الخاصة بملخصات Cacti كأي مصدر آخر |
| قتل القارئ أثناء دورة | يُكتب كل صف كاملًا، فتبقى قراءات كاملة. يكتشف Cacti العملية الميتة وتبدأ التالية فورًا وتكمل كل السلاسل |
| بدء قارئ ثانٍ | يسمح جدول عمليات Cacti بقارئ لكل مجمّع. يخرج المكرر فورًا برمز 0 ويسجل ملاحظة (مستوى Medium) دون إزعاج الأول |
| بدء الصيانة وانتهاؤها | يكبت Maint إشعارات الجهاز؛ يواصل Thold التقييم ويستمر استطلاع مصدر الملخص |
| انقطاع ترقية الإضافة | لا يتغير الإصدار المسجل إلا بعد نجاح كل خطوة؛ يكمل تحميل الصفحة أو دورة المجمّع التالية الترقية |

<a id="import-and-export"></a>
## الاستيراد والتصدير

راجع [صيغة الإعداد](configuration-format.md). الصيغة المختصرة:

```sh
php plugins/smokeping/cli/smokeping.php export --file=/var/backups/smokeping-config.yaml
php plugins/smokeping/cli/smokeping.php import --file=/var/backups/smokeping-config.yaml
```

<a id="logs"></a>
## السجلات

تكتب الإضافة في سجل Cacti بوسم `SMOKEPING`. يعرض `grep SMOKEPING log/cacti.log` إحصاءات القارئ (`SMOKEPING STATS`) وفشل الجرد واستيراد القوالب وكل استيراد إعداد طُبّق.
