# Logo

`logo.svg` and `logo_dark.svg` are the project logo for light and dark backgrounds, with PNG renderings at 720 by 720 pixels: a cactus wearing a badge that shows a SmokePing graph, above the text "SmokePing Cacti Plugin". The README shows the dark version when GitHub uses a dark theme.

The plugin is not affiliated with or endorsed by the SmokePing project or the Cacti project. "SmokePing" and "Cacti" appear in the plugin's name only to describe the software it connects.
